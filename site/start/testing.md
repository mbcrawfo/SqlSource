# Test code that uses a repository (mock or fake)

Have the code that uses the repository take its generated interface, `IUserRepository`, and give that code a fake of the interface in its tests, written by hand or by a mocking library: it holds the repository's public methods, with their signatures and documentation.  Register the repository as the interface, as in `services.AddSingleton<IUserRepository, UserRepository>()` beside its data source.  To put a method of your own on the interface, declare `public partial interface IUserRepository` with that member, and write it in the repository.  `<SqlSourceRepositoryInterfaces>false</SqlSourceRepositoryInterfaces>` in the project file turns the interfaces off, and `[SqlSourceGenerate(GenerateInterface = false)]` one type's; `InterfaceName` names one otherwise.  See [the interface](../reference/repositories.md#repository-interface) and [repository interfaces](../reference/repositories.md#repository-interfaces).
