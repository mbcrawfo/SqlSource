# Which database test projects a change to a path can affect.  pre-commit-validation.sh reads this file to skip the
# container projects that an uncommitted change cannot reach, and tests/SqlSource.Tests/Validation/ checks it.
#
# A line is `<scope> <pattern>`, where the scope is none (neither engine's projects), postgres, sqlserver or both, and
# the pattern is a path from the repository root with `/` as the separator.  `*` matches any run of characters, `/`
# included; every other character is literal, and `?` and brackets are refused.  The first line that matches a path
# decides its scope, so an exception goes before the broad line it carves out of.  A path that no line matches is both.
#
# A `project <postgres|sqlserver> <path>` line names a container project and the engine that runs it.
