# AGENTS.md - src/SqlSource.Tool/Describing/SqlServer/Proofs

How the proofs work: [the proofs of not null](../../../../../docs/architecture/sqlserver-describer.md#proofs-of-not-null).

- **The reader gives up rather than guess, and a misread must prove nothing.**  `SelectStatement`, `SelectBody` and `SelectItem` read a text they cannot follow as null, and a name they cannot read as a null `Name`, never as a likely answer: a column proved from a misread text is a silent wrong `false`.  A new form gets a test of what it must refuse beside what it reads.
- **A word that ends a range must be reserved, or its whole shape checked.**  A non-reserved word may be a name, as `window` may be an alias: `SelectBody` takes `WINDOW` as a clause only as `WINDOW name AS ( ... ), ...` to its end, and gives up otherwise ([the `SELECT`](../../../../../docs/architecture/sqlserver-describer.md#the-reader)).
- **A proof that holds for an expression that can be `NULL` is the worst bug here; one that gives up costs nothing.**  `ExpressionProofs` proves only [the forms](../../../../../docs/architecture/sqlserver-describer.md#the-forms); a form whose condition fails is `Proof.No`, never a leaf to ask, and anything else unknown is a leaf or `Proof.No`.  Every new case comes with one that must stay unproved.
- **A new form of a call is a row of `ExpressionProofs.FormsByName` and an arm of both its readings, `Form` and `FormType`**, whose switches name every kind with no `when`, so that a kind one leaves out fails the build.
- **A form that reads a value twice, `COALESCE` or the guarding `CASE`, proves only over a value answered not null or shown to give one value in a row** (`Proof.Stored`, `ExpressionProofs.OneValue`): SQL Server can evaluate an expression once for each reference, so the two reads of `NEWID()` can differ.  What `OneValue` does not read proves nothing.
- **Nothing that converts to its type proves unless no CLR type can be among its types** ([CLR types](../../../../../docs/architecture/sqlserver-describer.md#the-forms)): `CAST` and `CONVERT` only to a target of `CastTargets`, `COALESCE`, `GREATEST`, `LEAST`, `LAG`, `LEAD` and the guarding `CASE` only with every value they convert held of no CLR type.  What is a CLR type is `SqlServerTypes.MayBeClr` alone.
- **A filter proves a column only as `AnyOf(Operand, Stored)`**: it tests a value and the result reads it again.  `RowFilter`, `JoinChain` and `FilteredRows` compare names ordinally and read only the shapes [the filters](../../../../../docs/architecture/sqlserver-describer.md#filters) list, since a case-sensitive collation can make `X` another column.
- **A column of a set operator is proved only by every branch**, each with its own `ExpressionProofs` and `operands` call.  A proof's operand indexes move by the operands of the branches before it (`Proof.Shifted`).
- **Depth is `SelectBody.DepthChange`, walked by `SelectBody.AtLevel` and `SelectBody.ClosingParenthesis`.**  Do not write another rule of depth.
- **The only tokens `OperandsQuery` leaves out of a `FROM` are the `LEFT [OUTER]` of a join the `WHERE` makes inner.**
- **`OperandsQuery`'s text is slices of the user's SQL, cut at token offsets, and nothing else but `SELECT`, `,`, line breaks and the aliases `AS [n]`.**  Never rewrite, quote or add to a slice: the text reaches the server only as `@tsql`, and the line break before each `AS [n]` keeps a line comment inside an operand from swallowing it.  An answer whose visible rows are not the operands one for one proves no operand.
- **Nothing here sends anything.**  The reader reads the tokens of the user's text and calls no server, no exchange and no log; what a proof asks the server goes through the session's calls, by the rule of `Describing/SqlServer/` in `src/SqlSource.Tool/Describing/SqlServer/AGENTS.md`.
- **Tokens come from the generator's lexer, `DescriberSql.Lex` with `SqlDialectRules.SqlServer`**, so a comment, a string and a quoted name are split as the plan splits them.  Do not read the raw text for them.
