# AGENTS.md - src/SqlSource/Generation/Types

- **A new row of `Generation/Types/Maps/PostgresTypeMap.cs` needs its name in `Settings/TypeOverrides/TypeKeyNames.cs`**, which `PostgresTypeMapTests.Keys_OfTheMap_AreTheKnownPostgresNamesOfTheSettings` holds.  A new row of `Generation/Types/Maps/SqlServerTypeMap.cs` needs its name in `TypeKeyNames.KnownSqlServerNames`, which `SqlServerTypeMapTests.Keys_OfTheMap_AreTheKnownSqlServerNamesOfTheSettings` holds.  When the map learns the types of a new Npgsql major, raise `NpgsqlProbe.NewestKnownMajor`, which decides `SQLSRC248`; for a new Microsoft.Data.SqlClient major, raise `SqlClientProbe.NewestKnownMajor`, which decides `SQLSRC268`.
- **`Generation/Types/QueryTyper.cs` types a file by its engine.**  A type goes to the map of its class, `PostgresTypeMap` or `SqlServerTypeMap`, under its own driver's column, and the type override's entries are those of the file's engine, `SqlDescribableDialects.EngineOf`.  A help of `Diagnose` for one engine leaves the other's text as it is, and `OverrideLookup` makes its engine's delegate, and `QuerySettings.ResolveColumnTypes` merges the column types, once for each level of markers, never for each query or type.  See [types](../../../../docs/architecture/generator.md#types).
- **A library's row is step 4 of a type, below a marker, a column type and the type override, above the base map.**  Its `Detail` is `LibraryRows.PlaceOf`, so it sets `Place` and `Database`, never `Mapped`; `ConversionPlanner` converts it by an edge of the query's target or leaves it to the driver, never with `SQLSRC279` or `SQLSRC280`.  It keeps `WithoutLibrary` for the models to pick by output.
- **A row whose type has no C# type without its library (`Unreadable` or `NeedsSqlServerTypes` without it) stays, with `WithoutLibrary` null**, and that failure becomes the query's `QueryTypes.WithoutLibraryFailure`, never a diagnostic of the file: a `Models` claim gets it from `TypeModels.LibraryFailuresOf` instead of models.  Any other failure without the library replaces the row.  See [types](../../../../docs/architecture/generator.md#types).
- **`QueryTyper.LibrariesOf` resolves the library switch once for each distinct level of markers, never for each query or type.**  `SqlServerTypeMap` asks the rows after the type override at each level of an alias type's walk, and of a CLR user type only for NetTopologySuite's `geography` and `geometry` of `sys`.
- **Code that carries a level's type override carries both engines' arrays**, as `MappedTypeNames` and `FileTypesInput.TypeSettingsOf` do, and the type override is computed once for each distinct level of markers.  See [the type override](../../../../docs/architecture/generator.md#the-type-override).
