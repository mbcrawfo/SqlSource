# AGENTS.md - src/SqlSource/Generation/Emitting

- **A type's file starts with `// <auto-generated/>`, `#nullable enable` and `#pragma warning disable CS0108, CS0114`**, writes strings with `SymbolDisplay.FormatLiteral`, never as raw string literals, and uses `\n` line endings.  A model's file, from `Generation/Emitting/ModelEmitter.cs`, starts with the first two alone, and disables only the warnings of a mapped type that is obsolete or experimental.  A file of methods, from `Generation/Emitting/MethodEmitter.cs`, starts as a type's file when the methods go on the type, and with the first two alone for an extension class, and then disables only the warnings of a converter it calls or a property type it reads or binds that is obsolete or experimental, `TypeMethods.WarningIds`.  The one pragma inside a method is the `#pragma warning disable CA2100` and its `restore` around the `CommandText` of a query whose tokens build its SQL at run time, which the analyzer reports even in generated code; keep it ([why](../../../../docs/architecture/generator.md#query-methods)).
- **Nothing a token method writes may be hidden by a parameter.**  `Generation/Emitting/MethodWriter.cs` reads the state tuple by position, names the lambda's parameters with `GetUnusedName`, writes framework types from `global::` and `string` as the keyword.  A new identifier there needs the same care, and a row in both `Run_TokenWithAnAwkwardName_Compiles` of `tests/SqlSource.Tests/Generator/GeneratedSourceMethodTests.cs`, at C# 12 on the Roslyn floor too, and `Run_TokenWithAnAwkwardName_CompilesOnTheNewestCSharp` of `tests/SqlSource.Tests/Generation/Emitting/MethodWriterTests.cs`, at `LanguageVersion.Latest`.  A local of a query's method, from `Generation/Emitting/QueryMethodWriter.cs`, takes its name from `LocalNames`, and a name a token could hide gets a row in those two and in their siblings for a query's method, `Run_TokenWithAnAwkwardNameInAQueryMethod_Compiles` and `Run_TokenWithAnAwkwardNameInAQueryMethod_CompilesOnTheNewestCSharp`.  The row buffer of `Generation/Emitting/RowBuffer.cs` is a `file` struct that a method names from `global::`, so no token hides it; `RowBuffer.NameFor` names it otherwise when the type the methods go on has its name.
