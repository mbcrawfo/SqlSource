# TD-0071 recursive CTE proofs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prove a column of a CTE of several branches, a recursive one included, not null when every branch proves its item, the recursive members with the CTE's own columns taken as not null, and lower SQL Server's noise budget.

**Architecture:** `SelectStatement` reads a CTE's branches with the reader of set operators.  A leaf that is a column of such a CTE, read through a source no join can make `NULL`, gets a new alternative proof, `Proof.CteColumn(Cte, Column)`, beside the server's answer.  A new `CteProofs` proves each branch's item with its own `ExpressionProofs` and `operands` call, and decides the CTE's columns as the greatest fixed point: the largest set of columns every branch proves when the self references among them are taken as not null.

**Tech Stack:** C#, xUnit, Shouldly, SQL Server containers of the database tests.

**Spec:** `docs/tech-debt/TD-0071-sql-server-answers-nullable-for-columns-that-cannot-be-null.md`, the item "A recursive CTE's columns".

## Global Constraints

- A false non-nullable is the worst outcome; a misread proves nothing (`src/SqlSource.Tool/Describing/SqlServer/Proofs/AGENTS.md`).
- Names compare ordinally.  Every new case has one that must stay unproved.
- `operands` text stays slices of the user's SQL (`OperandsQuery.Text`), sent only as `@tsql`.
- Keep changes to `ColumnProofs.cs` small: `td-0071-clr-setop` changes it in parallel.
- Budgets of `RealisticNullabilityNoiseTests` move only for SQL Server.

## Review Focus

- A recursive member that reads a nullable column of its own source: `SELECT n + 1, NULL` style, or `c.parent_id` beside the CTE's column, must leave the column nullable.
- A self reference through an outer join, a comma, an `APPLY` or a derived table must not be taken as not null.
- An outer query that reads the CTE through a `LEFT JOIN` it does not cut must stay nullable.
- A CTE column of a CLR type, or one a string converts to, proves nothing (`NotClr` beside `CteColumn`).
- A CTE whose column list or branches do not agree in count, or with `*`, proves nothing.

### Task 1: Read a CTE's branches

**Files:** Modify `src/SqlSource.Tool/Describing/SqlServer/Proofs/SelectStatement.cs`; test `tests/SqlSource.Tool.Tests/Describing/SqlServer/Proofs/SelectStatementTests.cs`.

- `CtesEnd` reads a body with `ReadBranches`, whose names hold the CTE's own.
- Tests: a recursive CTE gives two branches, a CTE whose second branch is unreadable gives null `Branches`, a one-branch CTE keeps `Body`.

### Task 2: `Proof.CteColumn` and the leaf

**Files:** `Proof.cs`, `FilteredRows.cs`, `ExpressionProofs.cs`; tests in `ExpressionProofsTests.cs`.

- `Proof.CteColumn(int Cte, int Column)`: `Shifted` returns itself, and it never holds alone: only `CteProofs.Resolved` gives it a value.
- `FilteredRows.CteColumnOf(TokenRange range) : (int Cte, int Column)?`: a column alone whose source is the one source of a one-part name equal to a visible CTE's name, not optional, the CTE of several branches, each with as many items as the column list or the first branch, none a `*`, and exactly one column of that name.
- `ExpressionProofs.Leaf`: when `CteColumnOf` answers, `AnyOf(leaf's proof, AllOf(NotClr(leaf), CteColumn))`.

### Task 3: `CteProofs`

**Files:** create `src/SqlSource.Tool/Describing/SqlServer/Proofs/CteProofs.cs`; modify `ColumnProofs.cs`; tests `CteProofsTests.cs` beside the others.

- `CteProofs.Read(string sql, IReadOnlyList<TsqlToken> tokens, SelectStatement statement, IEnumerable<Proof> proofs, int asked)`: a worklist of the `CteColumn`s the proofs reach, each CTE's branches proved with `ExpressionProofs(tokens, branch, FilteredRows.Read(tokens, branch, ctes[..(cte + 1)], makesJoinsInner: false), asksLoneLeaf: true)`, then one `OperandQuery` per branch with operands, after the `asked` of the query's own.
- `Proof Resolved(Proof proof, IReadOnlyList<OperandFacts>? answers)`: each `CteColumn` replaced by `Always` or `Never`, by the greatest fixed point of its CTE, memoized per CTE.
- `ColumnProofs`: its queries followed by `CteProofs`'s, and `SourceOf` evaluates `ctes.Resolved(proof, answers).Holds(answers)`.
- Tests: the realistic tree query proved, a recursive member that reads a nullable column, a self reference through `LEFT JOIN`, a CTE read through an outer `LEFT JOIN`, a non-recursive `UNION ALL` CTE, a two-column cycle that holds only together.
