## Decision for item 6

The spec offers two fixes: a `case` for every key with a `default` that does nothing, as `SidecarTypeReader.ReadOther` has, or a test that each key array has a `case` for each key.

**Chosen: a `case` for every key, and a `default` that skips the value**, the way `SidecarCursor.NextKey` skips an unknown key, in all ten switches (`ReadOther`'s included, and `ReadTable`'s `if`/`else` becomes a switch).

- The code then says what it reads at each key, which is the whole of the problem: a key added to an array is never read as another key.
- A test that each array has a `case` for each key would have to parse the reader's source with Roslyn and pair each `switch` with the array its `NextKey` is given; that machinery would be larger than the fix, and would hold only the shape of the code.
- A `default` that skips, rather than does nothing: `NextKey` returns with the cursor at the key's value, so a `default` that does nothing would leave a key added without its `case` unread and the cursor out of step with the text, reading the value as the next key.  Skipping makes such a key an unknown key, which the reader rules already allow, and the round trip (`SidecarRoundTripTests`, every key the faker writes) fails for it, since the key is written and read back as absent.  The `default` is unreachable today; its comment says so.

`SidecarTypeReader`'s reliance on `bindName` being the last key of each parameter's array is removed rather than only tested, which the unit's brief asked for (a test, not only a comment): `ReadPostgres` and `ReadSqlServer` call `Require` with the array they read the keys by, as `ReadOther` already did, so the bits always line up whatever the place of `bindName`.  A test, `Read_ParameterTypeWithABindNameAndAKeyRemoved_IsMissingKeyAtTheType`, holds that a parameter's own type with `bindName`, before or after its other keys, still reports each key it cannot do without as missing, for each engine; it fails if the old reliance comes back with `bindName` moved.  `OtherParameterKeys` is written as `[.. OtherKeys, SidecarKeys.BindName]`, as the other two are, and the arrays stay private.  The `default` of every switch calls a new `SidecarCursor.SkipValue()`.
