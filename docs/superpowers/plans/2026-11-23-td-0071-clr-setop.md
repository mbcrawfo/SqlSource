# TD-0124 Set operator over a CLR type Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A SQL Server column of a CLR type that a set operator can make the type's Null is never answered not null on the server's word alone.

**Architecture:** `ColumnProofs` widens as well as narrows.  A visible row that may be of a CLR type (`SqlServerTypes.MayBeClr`) and that the server answers not null keeps that answer only when the row names a stored column of a table, the one fact the server gives that no conversion can reach, or when the query is a set operator whose every branch's item `operands` answers as a stored column of a CLR type.  Every other such column is nullable.  `TableRows` widens the rows of `table` by the same rule, so the table match compares like with like.

**Tech Stack:** C#, xUnit, Shouldly, SQL Server 2017 to 2025 in containers.

**Spec:** `td-0071-clr-setop`, which resolves TD-0124.

## Global Constraints

- A false non-null is the worst outcome and a false nullable only noise: a row the rule cannot clear is nullable.
- Every shape that breaks has a server test in `ProofTests` that describes it nullable and runs it to a `NULL` row.
- `README.md` is not edited.  TD-0124 is resolved, with its limit and its troubleshooting row.

## Measurements

On 2017 (CU31-GDR19), 2019 (CU32-GDR12), 2022 (CU27-GDR1) and 2025 (CU9-GDR1), the same on each.

| Fact | Result |
|----|----|
| `UNION ALL` of `geometry` or `geography` and a string, at the top level, in a derived table, a CTE, a CTE of a CTE, a view, a view of a view, a synonym, an inline function, three branches, nested parentheses | Not null, and a `NULL` row |
| `VALUES` of a CLR value and a string, of a CLR value and `'NULL'` | Not null, and a `NULL` row |
| `(d.c)`, `IIF(p, d.c, d.c)`, `ISNULL(d.c, x)`, `COALESCE(d.c, d.c)` over such a column | Not null, and a `NULL` row |
| A user's comparable CLR type under `UNION ALL`, `UNION`, of a string or of a binary that deserializes to its Null | Not null, and a `NULL` row |
| `INTERSECT` and `EXCEPT` whose first branch is a stored column of the type | The server names that column; the result is its values |
| `INTERSECT` and `EXCEPT` whose first branch is a string | The server names no source; `EXCEPT` answered nullable |
| The same column in every branch, two `geometry` columns, a `VALUES` or `UNPIVOT` of `geometry` columns | Not null, no `NULL` row, no source named |
| A plain column, through a derived table, a CTE, `OUTPUT inserted`, `TOP` | The row names the table's stored column |
| A view's or inline function's column | The row names the view or function |
| A table variable's column | No source named |
| `hierarchyid` from any string or binary tried | A value or an error, never `NULL` |
| Two CLR types of a set operator | Refused: operand type clash |
| A user's CLR type | `system_type_name` is `NULL` |

### Task 1: The rule

**Files:**
- Modify: `Proofs/ColumnProofs.cs`, `Proofs/OperandFacts.cs`, `Proofs/Proof.cs`, `Proofs/ExpressionProofs.cs`, `Proofs/OperandsQuery.cs`, `Columns/SqlServerColumns.cs`
- Test: `ColumnProofsTests`, `ProofTests` (unit), `OperandsQueryTests`, `SqlServerSessionProofTests`

- [ ] `SqlServerColumns.IsStored(row)` is the one spelling of a stored column, read by `OperandsQuery.AnswersOf` and the rule.
- [ ] `OperandFacts.Clr` and `Proof.Clr`: the operand is answered of a type that may be a CLR type.
- [ ] `ColumnProofs` marks each visible row that may hold a CLR Null, asks each branch's item `AllOf(Stored, Clr)` in a query of several branches, and answers the column nullable unless that holds.
- [ ] `TableRows` widens the rows of `table` by the same rule.
