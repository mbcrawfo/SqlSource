# Query generation 8.1: the methods - implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** For each query whose output resolves to `CodeGen` and whose entry, types and models are usable, generate an asynchronous ADO.NET method in place of its constant or token method, by the epic's signature, shapes, collection types, placement and connection rule, binding each parameter by value through one emitter per engine.

**Architecture:** The models stage records which model each type's query got (`ModelSet.Assignments`).  A new per-type chain gathers what the methods need of the type's files (`MethodsInput`), plans them (`MethodPlanner` → `TypeMethods`), checks the plans against each other and the project in one project-wide step (`MethodConflicts`), and writes one file per type (`MethodEmitter`, with `QueryMethodWriter` for each method and `ParameterBinder` for each engine's binding).  `TypeEmitter` stops writing a `CodeGen` query's constant or token method.  `UnexpectedRowCountException` joins the attribute's file.

**Tech Stack:** C# (`netstandard2.0` generator, `LangVersion` preview, Roslyn 4.8.0 floor), .NET 10 SDK, xunit v3, Shouldly; generated code is C# 12 on .NET 8+, compiled in tests against Npgsql 8.0.3, 9.0.3, 10.0.3 and Microsoft.Data.SqlClient 6.1.7, 7.1.1 (`NpgsqlReferences`, `SqlClientReferences`).

**Spec:** [`docs/superpowers/specs/2026-10-24-query-generation-phase-8-1-methods-design.md`](../specs/2026-10-24-query-generation-phase-8-1-methods-design.md), as amended by 8.0's pull request, with [the spike](../specs/2026-10-24-query-generation-phase-8-spike.md) and the epic's phase 8 section.

## Global Constraints

- Generated code uses nothing newer than C# 12 and runs on .NET 8 (`src/SqlSource/AGENTS.md`); the attribute file stays C# 7.3 with no nullable annotation.
- A method's file starts with `// <auto-generated/>`, `#nullable enable` (`GeneratedText.Header`) and, for a file that adds to the attributed type, `#pragma warning disable CS0108, CS0114` as `TypeEmitter`'s header has; strings by `SymbolDisplay.FormatLiteral`; `\n` line endings.
- Every framework type in a method is written from `global::`; `string`, `int`, `bool` as keywords; every model type as `global::<NamespaceText>.<Name>` (`global::<Name>` in the global namespace).  Every local and lambda parameter is chosen so that no token's name hides it.
- Every `await` has `.ConfigureAwait(false)`; `cancellationToken` reaches `OpenAsync`, `ExecuteReaderAsync`, `ExecuteNonQueryAsync` and `ReadAsync`.
- Reading: `CommandBehavior.Default` (spike §10); a not-null column `reader.GetFieldValue<T>(i)` with no `IsDBNull`; a nullable one `reader.IsDBNull(i) ? default(T?) : reader.GetFieldValue<T>(i)`, never `GetFieldValue<T?>` (spike §1, §2); a not-null column read as `global::Microsoft.Data.SqlTypes.SqlVector<float>` is checked with `IsNull` and throws `new global::System.InvalidCastException("Column '<name>' is null.")` (owner, 2026-10-24).
- Binding: `ParameterName` is the parameter list's name without `@` (spike §4); `Value` is the property, or `(object?)parameters.X ?? global::System.DBNull.Value` for a nullable property or any reference-typed one; nothing else is set (spike §7).
- New diagnostics are `SQLSRC272` to `SQLSRC276`, the next free ids, matching the spec.  Each is an Error tagged `NotConfigurable`, written out in full with a literal id, in `SqlDiagnostics.All`, `AnalyzerReleases.Unshipped.md` and a section of `docs/manual/diagnostics.md`.
- Values between steps are records with `EquatableArray<T>`; no Roslyn object crosses a step; every `Collect()` is followed by a `Select` that gives an `EquatableArray<T>`; every named step is in `TrackingNames` with a caching case; nothing a user writes makes the generator throw.
- Every commit passes `./pre-commit-validation.sh` run after its last edit.  No describer changes, so no floor-image run is needed.
- Tests: `Method_Scenario_Outcome`, Shouldly, `sealed` classes; a file in `tests/SqlSource.Tests/Generator/` starts with the shared line, ends in `Tests.cs`, uses C# 12 at most and Roslyn 4.8.0 API, and states its `OutputKind`; helpers go in `tests/SqlSource.Testing/Generator/`.

## Where merged code differs from the spec

- **The spec orders the constant's removal (its step 2) before the methods (step 3).**  Every commit must pass validation, and both example projects' `CodeGen/` classes read the constant through Dapper, so removing it first breaks their build until methods exist.  This plan builds the methods first (Tasks 3 to 5), then removes the constant and moves the examples onto the methods in one commit (Task 6).  The end-to-end projects' `NoteQueries` move to `Models` in Task 1, which changes nothing they generate today.
- **The connection argument is checked too.**  The spec checks `parameters` with `ArgumentNullException.ThrowIfNull`; the plan also checks `connection`, which would otherwise fail with a `NullReferenceException` at `State`.
- **Each parameter's statements are in a block of their own with one local name**, `parameter`, rather than `p0`, `p1`: a numbered name chosen against the tokens could collide with another numbered name.  The spec leaves the locals' names to the builder.
- **The methods file is its own source even under `Public`, `Internal` and `Private`**: a `partial` declaration of the attributed type in `<type hint>-Methods.g.cs`, so that `TypeOutput`'s inputs are not widened, as the spec's pipeline section requires.
- **The extension class's name is checked against namespaces too** (`SQLSRC276`), by reusing `ModelNameChecker.FindTaken`, since a namespace of that name is a compiler error in generated code just as a type is.

## Review Focus

1. **A token named like a generated local or a namespace** (`sql`, `command`, `reader`, `rows`, `row`, `span`, `state`, `wasClosed`, `parameter`, `System`, `App`) must compile with no warning, at C# 12 on the Roslyn floor and at `Latest`.  Task 4 adds the rows to both awkward-name theories.
2. **A sorted output model that is a record** must take each column into the property of its own name: columns `name, id` under `sort-output` give `new global::App.QDto(reader.GetFieldValue<int>(1), reader.GetFieldValue<string>(0))`.  Task 3 pins the text.
3. **A non-null reference parameter that holds `null` at run time** is sent as `DBNull.Value`, never `null`, which SqlClient would leave unsent (spike §5).  Task 3 pins the text.
4. **An attributed type nested in another, or generic, under `ExtensionClass`**: one top-level `<Name>Extensions`, internal unless the type and every type around it are public, compiling with no warning.  Task 4 compiles both.
5. **A model in the global namespace or under a namespace with an escaped keyword** (`@class.Rows`): the method's `global::`-qualified type compiles.  Task 4 compiles both.

The method's text, for `GetUser -> one-optional` with parameters and one token, under `ExtensionClass` (the shape of every case; the others differ where the notes say):

```csharp
    /// <summary>
    /// The <c>GetUser</c> query from <c>Users.sql</c>.
    /// </summary>
    /// <remarks>
    /// <code>
    /// SELECT id, name FROM users WHERE id = @id ORDER BY {{orderBy}}
    /// </code>
    /// </remarks>
    /// <param name="connection">The connection to run the query on.  It is opened when it is closed, and closed again when the method opened it.</param>
    /// <param name="parameters">The query's parameters.</param>
    /// <param name="orderBy">The text that replaces <c>{{orderBy}}</c>.</param>
    /// <param name="transaction">The transaction to run the query in, or null.</param>
    /// <param name="commandTimeout">The command's timeout in seconds, or null for the driver's.</param>
    /// <param name="cancellationToken">Cancels the query.</param>
    /// <returns>The row, or null when there is none.</returns>
    /// <exception cref="global::SqlSource.UnexpectedRowCountException">The query returned more than one row.</exception>
    public static async global::System.Threading.Tasks.Task<global::App.GetUserDto?> GetUser(
        this global::System.Data.Common.DbConnection connection,
        global::App.GetUserParams parameters,
        string orderBy,
        global::System.Data.Common.DbTransaction? transaction = null,
        int? commandTimeout = null,
        global::System.Threading.CancellationToken cancellationToken = default)
    {
        global::System.ArgumentNullException.ThrowIfNull(connection);
        global::System.ArgumentNullException.ThrowIfNull(parameters);
        global::System.ArgumentException.ThrowIfNullOrWhiteSpace(orderBy);
        var sql = string.Create(...);                 // `const string sql = "...";` without tokens
        var wasClosed = connection.State == global::System.Data.ConnectionState.Closed;
        if (wasClosed)
        {
            await connection.OpenAsync(cancellationToken).ConfigureAwait(false);
        }

        try
        {
            var command = connection.CreateCommand();
            await using var commandScope = command.ConfigureAwait(false);
            command.CommandText = sql;
            command.Transaction = transaction;
            if (commandTimeout.HasValue)
            {
                command.CommandTimeout = commandTimeout.Value;
            }

            {
                var parameter = command.CreateParameter();
                parameter.ParameterName = "id";
                parameter.Value = parameters.Id;
                command.Parameters.Add(parameter);
            }

            var reader = await command.ExecuteReaderAsync(global::System.Data.CommandBehavior.Default, cancellationToken).ConfigureAwait(false);
            await using var readerScope = reader.ConfigureAwait(false);
            if (!await reader.ReadAsync(cancellationToken).ConfigureAwait(false))
            {
                return null;                          // `one`: throw new global::SqlSource.UnexpectedRowCountException("GetUser", false);
            }

            var row = new global::App.GetUserDto(reader.GetFieldValue<int>(0), reader.IsDBNull(1) ? default(string?) : reader.GetFieldValue<string>(1));
            if (await reader.ReadAsync(cancellationToken).ConfigureAwait(false))
            {
                throw new global::SqlSource.UnexpectedRowCountException("GetUser", true);
            }

            return row;
        }
        finally
        {
            if (wasClosed)
            {
                await connection.CloseAsync().ConfigureAwait(false);
            }
        }
    }
```

Notes on the cases:
- Without parameters: no `parameters` argument, no check, no binding blocks.  Without tokens: no token arguments, and `const string sql = <literal>;`.  Under `no-token-validation`: no `ThrowIfNullOrWhiteSpace`.
- Type placement (`isExtension` false): `global::System.Data.Common.DbConnection connection` with no `this`.
- `many`: returns `Task<C>`; `var rows = <buffer>; while (await reader.ReadAsync(...)...) { rows.Add(<row>); } return <result>;`.  Buffer and result per `CollectionKind`: `Array`, `IEnumerable`, `IReadOnlyCollection`, `IReadOnlyList` → `new global::System.Collections.Generic.List<T>()` and `rows.ToArray()`; `List`, `IList`, `ICollection` → the list itself; `ImmutableArray` → `global::System.Collections.Immutable.ImmutableArray.CreateBuilder<T>()` and `rows.DrainToImmutable()`; `ImmutableList`, `IImmutableList` → `global::System.Collections.Immutable.ImmutableList.CreateBuilder<T>()` and `rows.ToImmutable()`.  `C` is `T[]`, `global::System.Collections.Generic.IEnumerable<T>` and so on, `global::System.Collections.Immutable.ImmutableArray<T>`.
- `none`: `await command.ExecuteNonQueryAsync(cancellationToken).ConfigureAwait(false);`, return type `Task`; `rowcount`: `return await ...;`, `Task<int>`.
- A class output: `new global::App.QDto { Id = <read 0>, Name = <read 1> }` in column order; a record: positional arguments in `ConstructorOrder`.
- A not-null `SqlVector<float>` column `i`: before the row, `var value<i> = reader.GetFieldValue<global::Microsoft.Data.SqlTypes.SqlVector<float>>(i); if (value<i>.IsNull) { throw new global::System.InvalidCastException("Column 'embedding' is null."); }` and the row reads `value<i>`.  The local's name comes from `LocalNames` (`"value" + i`).
- A nullable or reference-typed parameter: `parameter.Value = (object?)parameters.Name ?? global::System.DBNull.Value;`.
- Every local (`sql`, `wasClosed`, `command`, `commandScope`, `parameter`, `reader`, `readerScope`, `rows`, `row`, `value<i>`) and the lambda's `span` and `state` are taken from one `LocalNames` seeded with the token names and the five fixed argument names.
