## Global Constraints

- Test-only: nothing under `src/` changes.  A new case that fails because the product is wrong is not fixed here: report it to the controller with the failing case, and narrow the test meanwhile.
- No test depends on a real timer (`tests/AGENTS.md`); the watch tests move time through `WatchScene.Clock`.
- Assertions are Shouldly's; test names are `Method_Scenario_Outcome`; every test class is `sealed`.
- Keep `AboveTheTempFolder.SkipWhenInARepository(...)` lines at the start of the watch tests where they are.
- Don't rename tests the change does not rewrite (items 19 and 54 belong to another unit).
- `tests/AGENTS.md` is at its 8 KB limit: add nothing there.
- Run one class: `dotnet test --project tests/SqlSource.Tool.Tests -- --filter-class "*<ClassName>"`.  Run `./format.sh` before each commit.  Commit with `./pre-commit-validation.sh` passing.

## Where merged code differs from the spec

- Item 43's line numbers predate env-lookup (#247) and 108-run (#253).  `.env` is now read from the unit's folder only; the `.env` writes in `DotEnvRunTests` are now at more sites than the spec lists (also `:248`, `:283`, `:355`).  The fix covers every `DescribeScene`-based site.
- Item 8: `PassStarts` reads a log, so it goes on `WatchScene` (whose `Run.Folder` holds `run.log`), not on `FileChanges` as the spec's list says; the spec's goal, no class reaching into the test class `WatchTests`, is kept.
- Item 51: `TestSidecars.Postgres()` and `TestSidecars.Column(...)` already exist (`tests/SqlSource.Testing/Snapshot/TestSidecars.cs`); the fix is calling them.

## Review Focus

1. A factory whose `IsFolder` or `OldPath` differs from the inline record it replaces silently changes what a watch test checks: `Renamed(from, to, isFolder)` must build `new FileChange(Renamed, to, isFolder, from)`.
2. `TestSidecars.Column`'s default `nullableSource` is `Catalog`, where the replaced local builders passed `null`: pass `nullableSource: null` where the old value was null, or the expected sidecars change.
3. Item 33's byte comparison of `query.sql` and `capture.json` holds only if a renaming is the same for both runs; if it is keyed per run, report it rather than weakening the test silently.
4. Item 36: an event between `pass.end` and the next `pass.start` (or before the first pass, after the last) must fail the test.
5. Item 41: for `""` the error's path may not be a full path; the row's expected path must say what it is.
