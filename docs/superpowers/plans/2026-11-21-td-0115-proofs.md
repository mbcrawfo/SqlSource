# TD-0115 nullability proofs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close every mutation gap of the nullability proof files that could answer a nullable column not null, or record why a database test is its guard.

**Architecture:** Tests, and a source change only for a real false non-null, of which the review found one.  Texts one token from a form go in a new PostgreSQL test class and in the SQL Server proofs' theory.  The guard is `tools/mutation-test.sh tool` over the six files with the tests of their folders.

**Tech Stack:** C#, xUnit v3, Shouldly, Stryker.NET.

**Spec:** [`docs/tech-debt/TD-0115-tool-code-its-own-tests-do-not-check.md`](../../tech-debt/TD-0115-tool-code-its-own-tests-do-not-check.md).

## Global Constraints

- Scope: `TotalFunctions.cs`, `PlanExpression*.cs` and `ExpressionProofs.Calls.cs`.  The other files of the item are another unit's, and the item stays open.
- A false non-null is the worst outcome of the describers, and a false nullable is only noise.

## Review Focus

- A zero-argument window function that is no ranking, `first_value() OVER w1`, stays unknown.
- A `RANGE` frame that may leave out the current row stays unproved, as a `ROWS` frame does.
- A group the walk vetoes proves nothing as the operand of a cast or an `ANY`.
- A `CASE` whose last `END` is not its own stays unknown.
- A grand total over no rows: `GROUP BY ()`, `ROLLUP` and `CUBE` return no row on SQL Server 2017 and 2025, measured over an empty table, so `SUM` under them stays proved.
